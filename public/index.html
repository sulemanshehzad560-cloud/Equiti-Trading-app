[ BOOT ]

      
This app is the control desk for the Equiti Trader bot, which runs next to MetaTrader 5 on your PC or VPS. The bot decides and trades. This app watches it and can pause it or pull the plug.

      
    
        
  1. python main.py run --mode demo on the trading PC
    2. 
        
  2. Same PC: open http://localhost:8787. Phone: expose it over HTTPS (cloudflared tunnel --url http://localhost:8787)
    3. 
        
  3. Paste the address and the access token the bot printed into Settings
    4.
